# 🎙️ **Automatic Speech Recognition**

A web application built using React, Tailwind CSS, Node.js, Express js, powered by LLM for transcription.
The system supports both audio file upload and live speech recording transcription, and displays transcription results on-screen.

---
## 🚀 Features

- Transcription Modes
    - Upload & Transcribe audio files
    - Get transcription output instantly on the UI
    - Live Recording & Transcribe
    - Record live voice from the browser
    - Convert speech to text in real-time

- Transcription Output
    - Displays the full transcript
    - Shows: Character count, Word count
    - Actions: Copy transcription, Download transcription
---

## 🛠️ Tech Stack

- **Frontend** : React.js, Tailwind CSS
- **Backend** : Node.js, Express.js, REST APIs, Multer, WebSocket
- **AI** : Gemini LLM for Speech-to-Text transcription
